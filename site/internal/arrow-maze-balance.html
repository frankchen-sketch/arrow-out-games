Arrow Maze Balance Matrix

This page is a quick-read view of the current Arrow Maze difficulty curve. It is meant to answer a practical balancing question: what makes a level feel harder, and where does that pressure come from?

The source script is npm run analyze:arrow-maze. Use the script when the live level set changes, then update this page to match the current build.

Route Length

The shortest valid path. This is the base memory and execution load.

Turns

How often the optimal route changes direction. More turns usually means more rereads.

Open On Path

How many free-choice star tiles appear on the optimal route. These create live decision pressure.

False Edges

How many wrong exits branch away from those star tiles. This is the cleanest decoy signal.

Board Area

Total squares to scan. Bigger boards increase search load even before the player moves.

Curve Read

  • Levels 1-5 stay as warm-up route readers: short paths, small boards, and low branch noise.
  • Levels 6-11 now form the main decision band, where star-tile choices and wrong exits start to matter.
  • Levels 12-15 split the endgame into different pressure types: turn-heavy boards, one major branch-pressure spike, then a long final route.
  • If a later level feels weak in playtesting, compare whether its route length rose without enough turn pressure or false-edge cost.

How to Use This

  • If a level feels too easy, raise either route length or false-edge pressure; doing only one often produces flatter difficulty.
  • If a level feels annoying rather than smart, check whether turns and false edges both spiked at once.
  • If the late game feels repetitive, vary the pressure source instead of only making the route longer.
  • The current pass intentionally makes level 15 a cleaner turn-pressure finale rather than another branch-heavy board.
