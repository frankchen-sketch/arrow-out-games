Deploy Checklist

This page mirrors the current deployment checklist. The detailed working copy is maintained in DEPLOY_CHECKLIST.md.

Public Launch Path

  • Publish first on a Cloudflare Pages default subdomain.
  • Use no build command and keep the output directory set to site.
  • Push the launch-ready branch before creating the Pages project.

Domain and Post-Deploy Checks

  • Run npm run set-domain -- https://your-project.pages.dev.
  • Run npm run verify:production after replacing the domain.
  • Confirm the current public URL resolves publicly before treating device QA or AdSense review as complete.
  • Check the homepage, Arrow Maze, Contact, robots, sitemap, and 404 pages.

Email Routing

  • For the first pages.dev launch, keep a real mailbox visible on public pages, such as a839500525@126.com.
  • Send a real external test email to the currently published contact mailbox and confirm it is received before launch.
