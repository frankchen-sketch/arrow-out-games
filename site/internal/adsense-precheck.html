Review Build Rules

  • Arrow Maze is the only real playable game in the current public review build.
  • Arrow Out and Arrows Go remain noindex, follow overview pages.
  • No iframe game source, ad script, analytics SDK, or external tracking script is added in this stage.
  • The planned ad layout stays conservative: display-style placements only, with no popunder, forced interstitial, or default-on social bar.

Content and Trust Checks

  • Confirm the current public Arrow Maze build is stable on mobile after the touch-control anti-zoom fix.
  • Confirm Contact, About, Privacy, Terms, and DMCA are all accessible.
  • Confirm the public Contact page uses a real working mailbox before launch.
  • Confirm the currently published contact mailbox can receive a real external test message before submission.
  • Confirm no page introduces unsafe, infringing, or misleading content.

Submission Notes

  • Keep Arrow Maze as the main public entry point while the site is under review.
  • Do not expand the sitemap with noindex pages.
  • Treat unresolved public-domain reachability on the current public URL as a hard blocker for submission.
  • Level 10 finish visibility is no longer a submission blocker on the current public build.
